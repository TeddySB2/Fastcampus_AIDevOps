# 1-1 시연 메모 (강사용)

1-1 은 강사 시연이다. 수강생은 따라 하지 않고 2-1 부터 `p3-ch1-end` 에서 실습한다.

## 프롬프트 (plan 모드에서 그대로 붙여 넣는다)

```
docs/requirements/eks-dev.md(팀 회의 요구사항)와 CLAUDE.md(팀 규칙)를 읽고
specs/_template.md 형식으로 specs/eks-demo.md 초안을 써줘.
인프라는 아직 만들지 마. 지금 브랜치의 파일만 근거로 하고, 다른 브랜치 · 태그는 보지 마.
요구사항에 없거나 팀 규칙과 부딪히는 것만, 질문 3개 이내로 물어봐줘.
```

"다른 브랜치 · 태그는 보지 마" 가 없으면 Claude 가 main 의 완성본 스펙을 열어 비교하기도 한다.
PR 을 올릴지 물으면 "커밋만" 이라고 답한다. 1-1 은 스펙을 쓰는 데서 끝난다.

## 답변

시연 중 Claude 는 `docs/requirements/eks-dev.md` 의 "미정" 항목과 팀 규칙과 부딪히는 항목만 묻는다.
질문 문구와 순서는 실행마다 조금씩 다르다. **주제로 찾아서** 아래처럼 답한다.

| 질문 주제 | 이렇게 답한다 |
| --- | --- |
| 월 예산 · 비용 상한 | 월 $300. 넘으면 작업을 멈추고 보고한다 |
| 예산 알림 · 받을 사람 | AWS Budgets 는 사람이 콘솔에서 만든다. 알림은 담당자 메일 |
| 종료 시점 · 언제 내리나 | 작업한 날 destroy. 잊었을 때 대비로 `expires` 태그(최대 7일) |
| 장애 주입 예외 승인자 | @TeddySB2 |
| AWS 계정 ID | 적지 않는다. 자리표시만 둔다 (공개 저장소) |
| 그 밖의 질문 | "요구사항 문서대로" 라고 답한다. 문서에 없는 선택지는 고르지 않는다 |

선택지 화면(AskUserQuestion)이 뜨면 위 답에 해당하는 항목을 고르고, 없으면 "Other" 에 위 문장을 그대로 적는다.
