# 1-2 시연 메모 (강사용)

1-2 는 강사 시연이다. 1-1 에서 계약서를 커밋한 브랜치에서 이어서, Claude 를 새 세션으로 연다.
촬영이 끝나면 이 브랜치의 최종 커밋으로 `p3-ch1-end` 태그를 만든다.

## 시연 ① 프롬프트

```
CLAUDE.md 의 "환경 사실" 과 계약서 "2. 환경" 이 서로 다른 말을 하는 곳을 찾아줘.
고치기 전에 중요한 것만 3개 이내로 보여주고, 같은 값을 두 곳에 두지 않게 CLAUDE.md 쪽만 고쳐줘.
계약서는 바꾸지 말고, 이 브랜치에서 커밋까지만 해줘.
```

## 시연 ① 에서 Claude 가 물으면

| 질문 | 답 |
| --- | --- |
| 값을 CLAUDE.md 에 복사할지, 계약서를 참조할지 | 참조로. 값은 계약서 한 곳에만 둔다 |
| 계약서의 중복 문장도 정리할지 | 아니. 이번에는 CLAUDE.md 의 환경 사실만 고친다 |
| 계정 ID 를 옮길지 | 옮기지 않는다 (공개 저장소) |
| 어느 브랜치에서 할지 · PR 을 올릴지 | 이 브랜치(ch1)에서 커밋만 |
