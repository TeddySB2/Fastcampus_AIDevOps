# 1-2 실습 준비: 어떤 계약서로 이어갈까

1-1 에서 쓰던 브랜치에서 그대로 이어간다. 시작 전에 계약서를 정한다.

## 1-1 을 한 경우

먼저 기준 계약서와 비교한다.

```bash
git status -s                                   # 계약서가 커밋돼 있는지 (안 돼 있으면 커밋)
git diff p3-ch1-end -- contracts/eks-demo.md
```

### A. 내 계약서로 계속

실행 전 확인 · 제외 항목 · 되돌리기 · 종료 기준, 네 가지가 기준과 같으면 그대로 `claude` 를 연다.
Claude 가 찾는 어긋남이 강의 화면과 조금 다를 수 있다.

### B. 기준 계약서로 맞추고 계속 (강의 화면과 똑같이 따라가려면)

```bash
git restore --source p3-ch1-end -- contracts/eks-demo.md
git commit -m "기준 계약서로 맞춤"
git show HEAD~1:contracts/eks-demo.md           # 내 초안은 이전 커밋에 남아 있다
```

## 1-1 을 건너뛴 경우

```bash
git switch -c ch1 p3-ch1-end
```

## 시작

계약서를 바꿨다면 Claude 를 새 세션으로 연다. 새 세션이어야 CLAUDE.md 와 계약서를 다시 읽는다.

```bash
claude
> /memory        # ./CLAUDE.md 와 @contracts/eks-demo.md 가 보이면 준비 완료
```

## 실습 ① 프롬프트

```
CLAUDE.md 의 "환경 사실" 과 계약서 "2. 환경" 이 서로 다른 말을 하는 곳을 찾아줘.
고치기 전에 중요한 것만 3개 이내로 보여주고, 같은 값을 두 곳에 두지 않게 CLAUDE.md 쪽만 고쳐줘.
계약서는 바꾸지 말고, 이 브랜치에서 커밋까지만 해줘.
```

## 실습 ① 에서 Claude 가 물으면

| 질문 | 답 |
| --- | --- |
| 값을 CLAUDE.md 에 복사할지, 계약서를 참조할지 | 참조로. 값은 계약서 한 곳에만 둔다 |
| 계약서의 중복 문장도 정리할지 | 아니. 이번에는 CLAUDE.md 의 환경 사실만 고친다 |
| 계정 ID 를 옮길지 | 옮기지 않는다 (공개 저장소) |
| 어느 브랜치에서 할지 · PR 을 올릴지 | 이 브랜치(ch1)에서 커밋만 |
